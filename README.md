# Anywhere Try-On — powered by Decart

Try on clothes from any fashion website. Click a product image (or drag it
onto the drop dock) and see yourself wearing it in realtime via Decart's
`lucy-vton-latest` model.

## Setup

1. `npm install && npm run build` (Node 18+, bundles the Decart SDK)
2. Get an API key at https://platform.decart.ai
3. Chrome → `chrome://extensions` → enable **Developer mode** → **Load unpacked**
   → select this folder (Chrome 116+)
4. Click the extension icon to open the side panel, paste your API key, Save

## Token server (recommended)

Keeps your raw `dct_` key off the browser and enables AI-generated prompts:

1. `cp .env.example .env` → fill in `DECART_API_KEY` (and `OPENAI_API_KEY` for AI prompts)
2. `npm run server` → listens on http://localhost:8787
3. In the panel, paste `http://localhost:8787` into the token-server field → Save

Each try-on session mints a 10-minute client token via `POST /tokens`; garment
prompts are generated by a vision LLM from the garment image plus a frame of
your camera (`POST /enhance-prompt`), falling back to the built-in heuristic
prompt if the server is unavailable.

## Use

1. Open any fashion site (Zara, H&M, SSENSE, …)
2. Hover a product image → **Try it on ✨**, or drag it onto the
   **"Drop to try on"** dock
3. Allow camera access when prompted — you'll see yourself wearing the item live
4. Click another item to switch outfits instantly (no reconnect)

You can also drop local image files onto the video, or use **Upload garment**.

## Notes

- Realtime sessions are billed per minute by Decart; **Fast mode** is 2x
  (lower latency, US region only).
- Best results with clean garment shots (item only, plain background, ≥512px).
  Model-worn photos still work — the model matches the garment.
- For a public release, don't ship user API keys: always use the token server.
